# Vision checkpoint benchmark

ADE20K checkpoint evaluations for EfficientViT-B1, SegFormer-B0, SCTNet-S and SeaFormer-Tiny. See `scripts/` for original evaluation commands, `results/` for saved metrics, and `logs/` for execution output. The main README reports preliminary validation mIoU. No combined KWS+vision latency or Jetson performance is reported yet.

Pretrained weights and ADE20K images are deliberately excluded. For full reproduction, record checkpoint sources, upstream revisions, input resolution, preprocessing, dataset split, and environment.
